# 卡比的美食比赛 · 人机对战

一个不需要安装、打开即玩的连连看小游戏。每个色块上都带有主题 emoji，用颜色和图案一起辨认同色块。

## 开始游戏

双击 `index.html`，用 Chrome / Edge / Firefox 打开即可。不需要服务器，也不需要联网。

## 玩法

- 棋盘为 12 × 10 网格，每局根据棋谱生成 **96～120 个主题色块**。
- 依次点击两个**颜色/食物相同**的色块。
- 连接线只能水平或垂直，最多转弯 **2 次**；也可以从棋盘边缘外绕行。
- 你和电脑同时抢着消除，限时 **60 秒**。计分按**消除的方块数**计算，不按对数；消除方块更多的一方获胜。
- 点击方块会播放一次短音效 `00be - SE_KETTEI.wav`。
- 当棋盘上没有可消除组合时，本局立即结束并直接按当前方块得分结算，不再自动重排。
- 快捷键：按 `E` 释放玩家技能，按 `P` 或 `Esc` 暂停。
- 暂停菜单可以继续游戏、重新开始本局，或直接**返回主菜单**。
- 可选三档电脑难度：
  - **春风**：4.4 秒/手，电脑不发动角色技能。
  - **标准**：3.0 秒/手，电脑每次蓄力有 50% 概率发动技能。
  - **狂野**：1.9 秒/手，电脑必定发动技能。
- 技能新增或重排的方块会直接保持可见，不会先消失再重新出现。
- 手机竖屏使用全高游戏舞台：棋盘会利用左右虚拟边框的宽度放大到接近满宽，玩法区不再只挤在屏幕上半部分。
- 手机端可以**双击棋盘**（或空白舞台）释放玩家技能，不必去点按钮。

## 方块主题

开始页可以在三套图案主题之间切换；主题只改变方块上的 emoji，不改变方块颜色和配对规则：

| 主题 | 名称 | 图案 |
| --- | --- | --- |
| A | 蔬果乐园 | 🍎 🍊 🍋 🥦 🥝 🫐 🍇 🍑 |
| B | 烘焙甜点 | 🍰 🥐 🍞 🧁 🍦 🍩 🥧 🍪 |
| C | 主食快餐 | 🍕 🍔 🍟 🥪 🍜 🍣 🥟 🌭 |

切换主题后，开始页的预览和开始后的棋盘会一起更新；角色技能产生的吸入、分裂和重排方块也会使用当前主题。

## 角色与技能

开局可以选择自己的角色，也可以指定电脑角色或让电脑**随机**选角色。玩家技能条每 **5 秒**充满；电脑技能条每次会在 **5～7 秒**之间随机充满。

- 开始页右上角有「玩法」按钮，不必先开始游戏就能查看说明。
- 玩家技能：点击「释放」或按 `E` 手动触发；开始页的「玩家自动」是直接开关，点击即可开启/关闭，不会进入游戏；游戏中也可以在右上角「设置」里调整。
- 电脑技能：蓄力完成后按当前难度判定是否发动——春风不发动、标准每次 50% 概率、狂野必定发动；不需要额外设置。
- 技能动画播放期间仍然可以继续点击、消除方块。

### 卡比 · 超级吸入

- 代表色：粉色；头像：🍑
- 优先找出 **3 对同一花色/食物**、且互不重叠的可连色块并自动消除。
- 被选中的色块会像被吸入屏幕底部的旋涡一样消失，消除的方块数计入释放者得分。

### 帝帝帝大王 · 锤子敲击

- 代表色：黄色；头像：✌️
- 释放时底部出现敲击闪光，随后整个游戏区域震动。
- 随机选出 **4 对同色方块**，把它们与棋盘上的相邻格交换位置，让每对最终落在相邻的两个活动格里。
- 玩家释放后，电脑会有 **1 秒隐形冷却**，暂时不能选择方块；不显示倒计时。
- 不增加或减少色块数量，也不直接得分。

### 魅塔骑士 · 新月斩击

- 代表色：深蓝色；头像：🫐
- 释放时全屏出现蓝白色斩击。
- 随机让最多 **4 个方块**在原地分裂，各自在旁边生成一个同色方块，形成相邻并列对。
- 为保持颜色仍然成对，同一颜色会成对分裂；空位不足时会少分裂或等待空位。
- 玩家分裂出的新方块及对应的原方块，在生成后的 **2.5 秒内不会被电脑选为消除目标**，避免被卡比的旋涡或普通消除立刻吸走；保护结束后恢复正常。

### 塔狼蛛 · 魔术蛛丝

- 代表色：墨绿色；头像：🕷️
- 随机选择 **3 对同色方块**结出蜘蛛网。
- 被蛛网覆盖的方块在 **3 秒内不能由对方点击/消除**；释放蛛网的一方仍然可以点击并消除自己的蛛网方块。
- 3 秒后蛛网消失，剩余方块会淡出并一起消除，按方块数计入塔狼蛛释放者的得分。
- 结网期间这些方块不会被其他技能换位或分裂，避免破坏成对关系。

### 魔噜酷 · 黑洞吸收

- 代表色：浅紫色；头像：🤡（没有单独的“彩球” emoji，使用小丑头像）
- 释放时出现紫色黑洞旋涡。
- 从棋盘的随机位置吸入 **7～11 个紧挨在一起的方块**，不要求颜色成对。
- 黑洞口位于棋盘内的方块下层，不会挡住方块点击和辨认。
- 游戏开始后播放循环背景音乐《12. Crash! Gourmet Race》；暂停时音量降低 20%，继续时恢复；结算时淡出，回主菜单时停止。
- 按下暂停时播放 `00ba - SE_PAUSE.wav`；帮助/设置触发的自动暂停不会播放该音效。
- 被吸入的方块数直接计入魔噜酷释放者的得分；技能会同时减少场上剩余方块数。

## 棋谱

开局默认选择「随机」，每局会随机抽取一种棋谱；也可以直接点选喜欢的棋谱。不同棋谱的轮廓和色块数量不同：

| 棋谱 | 色块数 | 形状 |
| --- | ---: | --- |
| 满堂阵 | 120 | 铺满全盘 |
| 拱门阵 | 112 | 上方密、下方留门洞 |
| 菱形阵 | 108 | 中间宽、两头收 |
| 双塔阵 | 104 | 左右双塔、底部相连 |
| 阶梯阵 | 100 | 逐级收窄的台阶 |
| 十字阵 | 96 | 四通八达的十字 |

选择「随机」后，点击「再来一局」或回到开始页继续开局时，会避开上一局刚用过的棋谱；暂停菜单里的「重新开始本局」则保留当前棋谱。

## 部署到 GitHub Pages

这个游戏是纯静态页面，但必须把以下文件放在**同一个目录**并一起提交，不能只上传 `index.html` 和 `style.css`：

```text
index.html
style.css
layouts.js
logic.js
game.js
00be - SE_KETTEI.wav
00ba - SE_PAUSE.wav
12. Crash! Gourmet Race.mp3
```

常见问题：

- GitHub Pages 运行在区分大小写的 Linux 环境。`game.js`、`logic.js`、`layouts.js` 必须与 HTML 中的引用大小写完全一致；Windows 本地能打开不代表线上能找到文件。
- GitHub Pages 的发布分支/目录要指向包含全部文件的目录，提交后等待 Pages 重新构建。
- 不要通过 GitHub 的代码预览页或第三方 HTML 预览服务打开，使用正式的 Pages 地址。
- 修改后建议强制刷新（`Ctrl + F5`），避免浏览器继续使用旧的 JS/CSS 缓存。
- 如果页面只显示静态标题、难度按钮，主题/棋谱/角色区域为空，打开浏览器开发者工具的 Console 和 Network 检查：`game.js`、`logic.js`、`layouts.js` 是否有 404、MIME 或语法错误。

## 文件说明

- `index.html`：页面结构与开始、暂停、帮助、设置、结算界面。
- `style.css`：视觉样式、主题选择器、棋盘布局、角色卡、技能条、吸入、震屏、斩击、蛛网与黑洞特效。
- `layouts.js`：棋谱模板、轮廓和色块数量。
- `logic.js`：棋盘生成、同色匹配、寻路、四对换位、并列对、分裂、相邻团吸入逻辑。
- `game.js`：游戏流程、随机棋谱、主题切换、双方角色与技能、实时计时、电脑对手与结算。
- `00be - SE_KETTEI.wav`：点击方块时播放的短音效，部署时必须和页面放在同一目录。
- `00ba - SE_PAUSE.wav`：按下暂停时播放的音效，部署时必须和页面放在同一目录。
- `12. Crash! Gourmet Race.mp3`：游戏开始后的循环背景音乐，暂停时降低 20% 音量，结算时淡出，部署时必须和页面放在同一目录。

## 操作小贴士

- 先扫视边缘和四角，这些位置的色块通常更容易连。
- 点错颜色会自动把选择切换到新色块，不需要先取消。
- 魅塔骑士需要空位才能分裂；卡手时先消掉几对，再按 `E`。
- 棋盘一旦无解会立即结算，留给你挽救的时间不多，尽量优先制造新的可消组合。
