# 卡比的美食比赛 · 对手对战

一个不需要安装、打开即玩的连连看小游戏。每个色块上都带有主题 emoji，用颜色和图案一起辨认同色块。

## 开始游戏

双击 `index.html`，用 Chrome / Edge / Firefox 打开即可。不需要服务器，也不需要联网。

## 玩法

- 棋盘为 12 × 10 网格，每局根据地图生成 **96～120 个主题色块**。
- 依次点击两个**颜色/食物相同**的色块。
- 连接线只能水平或垂直，最多转弯 **2 次**；也可以从棋盘边缘外绕行。
- 你和对手同时抢着消除，计分按**消除的方块数**计算，不按对数；消除方块更多的一方获胜。
- 开始页可以选择**经典模式**或**无尽模式**。经典模式限时 60 秒；无尽模式没有时间限制，玩家自己输入回合数（1～20）。
- 无尽模式每一回合都会换一张新棋盘；当前回合的方块全部消除或没有可消除组合时，立即进入下一回合。全部回合结束后，累计消除方块最多的一方获胜。
- 点击方块会播放一次短音效 `audio/00be - SE_KETTEI.wav`。
- 设置里可以分别开关「背景音乐」和「音效」；音效开关控制点击、暂停、主菜单按钮、弹窗关闭和角色特技音效。
- 选择角色或地图时播放 `audio/00bc - SE_CURSOR.wav`。
- 关闭玩法、设置、地图、角色或暂停弹窗时播放 `audio/00bf - SE_CANCEL.wav`。
- 卡比发动「超级吸入」时播放 `audio/00f5 - SE_SUIKOMI.wav`，吸入结束后淡出。
- 魔噜酷发动「黑洞吸收」时同时播放 `audio/01ab - SE_MARKHOLE1.wav` 和 `audio/01b1 - SE_MARK_WR2.wav`。
- 游戏开始后播放循环背景音乐《12. Crash! Gourmet Race》；暂停时音量降低 50%，继续时恢复；结算时淡出，回主菜单时停止。
- 按下暂停时播放 `audio/00ba - SE_PAUSE.wav`；游戏进行中打开玩法或设置触发自动暂停时也会播放，主菜单打开则不播放。
- 当棋盘上没有可消除组合时，本局立即结束并直接按当前方块得分结算，不再自动重排。
- 连续消除会累积 COMBO：普通消除 +1，卡比会按消除对数增加，蛛网会按消散对数增加；选错颜色、连不通，或 2 秒内没有新的消除时 COMBO 归零。
- 棋盘上会随机出现带右下角🔥标记的**复制能力方块**（每局 5 个）。玩家或对手消除这类方块后，会为对应一方获得「烈火」；玩家获得时播放 `audio/00f3 - SE_PWUP.wav`，对手获得时不播放。
- 复制能力方块一次只能保存一个能力；新能力会覆盖旧能力。获得后开始 **3 秒**倒计时，倒计时结束前可以反复使用，倒计时归零才消失。
- 烈火会以点击到的方块为中心，消除中心块加上下左右 4 个相邻方块，共最多 5 块；每次使用不会消耗能力本身。
- 对手获得复制能力后，会按当前难度的特技发动概率决定是否使用，并使用随机方块作为烈火中心。
- 烈火波及复制能力方块时，也可能重新获得一个新的烈火能力。
- 快捷键：按 `E` 释放玩家特技，按 `P` 或 `Esc` 暂停。
- 暂停菜单可以继续游戏、重新开始本局，或直接**返回主菜单**。
- 可选三档难度：
  - **春风**：4.4 秒/手，对手不发动角色特技。
  - **标准**：3.0 秒/手，对手每次蓄力有 50% 概率发动特技。
  - **狂野**：1.9 秒/手，对手必定发动特技。
- 特技新增或重排的方块会直接保持可见，不会先消失再重新出现。
- 手机竖屏使用全高游戏舞台：棋盘会利用左右虚拟边框的宽度放大到接近满宽，玩法区不再只挤在屏幕上半部分。
- 手机端可以**双击棋盘**（或空白舞台）释放玩家特技，不必去点按钮。

## 方块主题

开始页可以在三套图案主题之间切换；主题只改变方块上的 emoji，不改变方块颜色和配对规则：

| 主题 | 名称 | 图案 |
| --- | --- | --- |
| A | 蔬果乐园 | 🍎 🍊 🍋 🥦 🥝 🫐 🍇 🍑 |
| B | 烘焙甜点 | 🍰 🥐 🍞 🧁 🍦 🍩 🥧 🍪 |
| C | 主食快餐 | 🍕 🍔 🍟 🥪 🍜 🍣 🥟 🌭 |

切换主题后，开始页的预览和开始后的棋盘会一起更新；角色特技产生的吸入、分裂和重排方块也会使用当前主题。

设置里还可以按角色切换 6 套界面配色：卡比（粉）、帝帝帝（金黄）、魅塔骑士（蓝）、头巾瓦豆鲁迪（橙）、塔狼蛛（墨绿）、魔噜酷（浅紫）。界面主题只改变按钮、光晕、选中状态和星星颜色，不影响棋盘图案和玩法。

消除方块时会迸出星星粒子；普通配对、卡比特技、蛛网消散都会触发。

## 角色与特技

开局可以选择自己的角色，也可以指定对手角色或让对手**随机**选角色。玩家特技条每 **5 秒**充满；对手特技条每次会在 **5～7 秒**之间随机充满。

- 开始页右上角有「玩法」按钮，不必先开始游戏就能查看说明。
- 玩家特技：点击「释放」或按 `E` 手动触发；开始页的「特技自动」是直接开关，点击即可开启/关闭，不会进入游戏；游戏中也可以在右上角「设置」里调整。
- 对手特技：蓄力完成后按当前难度判定是否发动——春风不发动、标准每次 50% 概率、狂野必定发动；不需要额外设置。
- 特技动画播放期间仍然可以继续点击、消除方块。
- 玩家发动特技时，棋盘面板左上边线会划入一个黑底、角色代表色斜线的三角形头像横幅；对手发动时从右上边线对称划入。横幅只显示角色 emoji，停留约 2 秒后再从边线划出；整个横幅会被裁切在棋盘面板内部，不会露到面板外。

### 卡比 · 超级吸入

- 代表色：粉色；头像：🍑
- 优先找出 **3 对同一花色/食物**、且互不重叠的可连色块并自动消除。
- 被选中的色块会像被吸入屏幕底部的旋涡一样消失，消除的方块数计入释放者得分。

### 帝帝帝大王 · 锤子敲击

- 代表色：黄色；头像：✌️
- 释放时底部出现敲击闪光，随后整个游戏区域震动。
- 随机选出 **4 对同色方块**，把它们与棋盘上的相邻格交换位置，让每对最终落在相邻的两个活动格里。
- 玩家释放后，对手会有 **1 秒隐形冷却**，暂时不能选择方块；不显示倒计时。
- 不增加或减少色块数量，也不直接得分。

### 魅塔骑士 · 新月斩击

- 代表色：深蓝色；头像：🫐
- 释放时全屏出现蓝白色斩击。
- 随机让最多 **4 个方块**在原地分裂，各自在旁边生成一个同色方块，形成相邻并列对。
- 为保持颜色仍然成对，同一颜色会成对分裂；空位不足时会少分裂或等待空位。
- 玩家分裂出的新方块及对应的原方块，在生成后的 **2.5 秒内不会被对手选为消除目标**，避免被卡比的旋涡或普通消除立刻吸走；保护结束后恢复正常。

### 头巾瓦豆鲁迪 · 直升回旋

- 代表色：橙色；头像：🍊
- 释放时棋盘底部出现倾斜高速旋转的长光刃和上升气流，不绘制实体长矛或风扇。
- 无视地图阵型，直接将 **4 对同色方块**吹到棋盘最顶部中央的一整行，并把每一对并排放在一起。
- 顶部目标格如果没有原有方块可以替换，对应来源位置会直接留空；被蛛网覆盖的方块不会作为来源。
- 玩家释放后，对手会在 1 秒内无法选择方块，与帝帝帝大王的换位保护一致。
- 这个特技只移动方块，不直接消除方块。

### 魔噜酷 · 黑洞吸收

- 代表色：浅紫色；头像：🤡（没有单独的“彩球” emoji，使用小丑头像）
- 释放时出现紫色黑洞旋涡。
- 从棋盘的随机位置吸入 **7～11 个紧挨在一起的方块**，不要求颜色成对。
- 黑洞口位于棋盘内的方块下层，不会挡住方块点击和辨认。
- 被吸入的方块数直接计入魔噜酷释放者的得分；特技会同时减少场上剩余方块数。

### 塔狼蛛 · 魔术蛛丝

- 代表色：墨绿色；头像：🕷️
- 随机选择 **3 对同色方块**结出蜘蛛网。
- 被蛛网覆盖的方块在 **3 秒内不能由对方点击/消除**；释放蛛网的一方仍然可以点击并消除自己的蛛网方块。
- 3 秒后蛛网消失，剩余方块会淡出并一起消除，按方块数计入塔狼蛛释放者的得分。
- 结网期间这些方块不会被其他特技换位或分裂，避免破坏成对关系。

选择「随机」后，点击「再来一局」或回到开始页继续开局时，会避开上一局刚用过的地图；暂停菜单里的「重新开始本局」则保留当前地图。

## 部署到 GitHub Pages

这个游戏是纯静态页面，但必须把以下文件放在**同一个目录**并一起提交，不能只上传 `index.html` 和 `style.css`：

```text
index.html
style.css
star-allies.css
layouts.js
logic.js
game.js
fonts/
  乐米沐和圆体.ttf
audio/
  00be - SE_KETTEI.wav
  00bb - SE_SELECT.wav
  00bc - SE_CURSOR.wav
  00bf - SE_CANCEL.wav
  00f3 - SE_PWUP.wav
  00ba - SE_PAUSE.wav
  00f5 - SE_SUIKOMI.wav
  01ab - SE_MARKHOLE1.wav
  01b1 - SE_MARK_WR2.wav
  12. Crash! Gourmet Race.mp3
```

常见问题：

- GitHub Pages 运行在区分大小写的 Linux 环境。`game.js`、`logic.js`、`layouts.js` 必须与 HTML 中的引用大小写完全一致；Windows 本地能打开不代表线上能找到文件。
- GitHub Pages 的发布分支/目录要指向包含全部文件的目录，提交后等待 Pages 重新构建。
- 不要通过 GitHub 的代码预览页或第三方 HTML 预览服务打开，使用正式的 Pages 地址。
- 修改后建议强制刷新（`Ctrl + F5`），避免浏览器继续使用旧的 JS/CSS 缓存。
- 如果页面只显示静态标题、难度按钮，主题/地图/角色区域为空，打开浏览器开发者工具的 Console 和 Network 检查：`game.js`、`logic.js`、`layouts.js` 是否有 404、MIME 或语法错误。

## 文件说明

- `index.html`：页面结构与开始、暂停、帮助、设置、结算界面。
- `style.css`：视觉样式、主题选择器、棋盘布局、角色卡、特技条、吸入、震屏、斩击、蛛网与黑洞特效。
- `layouts.js`：地图模板、轮廓和色块数量。
- `logic.js`：棋盘生成、同色匹配、寻路、四对换位、并列对、分裂、相邻团吸入、成对方块升顶逻辑。
- `game.js`：游戏流程、随机地图、主题切换、双方角色与特技、实时计时、对手与结算。
- `audio/00be - SE_KETTEI.wav`：点击方块时播放的短音效。
- `audio/00bb - SE_SELECT.wav`：主菜单普通按钮的点击音效。
- `audio/00bc - SE_CURSOR.wav`：选择角色、地图、界面主题或切换设置开关时的音效。
- `audio/00bf - SE_CANCEL.wav`：关闭各类弹窗时的取消音效。
- `audio/00f3 - SE_PWUP.wav`：玩家获得复制能力「烈火」时的强化音效。
- `audio/00ba - SE_PAUSE.wav`：按下暂停时播放的音效。
- `audio/00f5 - SE_SUIKOMI.wav`：卡比「超级吸入」的特技音效，吸入结束后淡出。
- `audio/01ab - SE_MARKHOLE1.wav`、`audio/01b1 - SE_MARK_WR2.wav`：魔噜酷「黑洞吸收」同时播放的双音效。
- `audio/12. Crash! Gourmet Race.mp3`：游戏开始后的循环背景音乐，暂停时降低 50% 音量，结算时淡出。
- 所有音频统一放在 `audio/` 目录，部署时整个目录一起上传。

## 操作小贴士

- 先扫视边缘和四角，这些位置的色块通常更容易连。
- 点错颜色会自动把选择切换到新色块，不需要先取消。
- 魅塔骑士需要空位才能分裂；卡手时先消掉几对，再按 `E`。
- 棋盘一旦无解会立即结算，留给你挽救的时间不多，尽量优先制造新的可消组合。
