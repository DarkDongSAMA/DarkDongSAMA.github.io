# 纯色连连看 · 人机对战

一个不需要安装、打开即玩的连连看小游戏。色块暂时全部使用纯色，没有图案。

## 开始游戏

双击 `index.html`，用 Chrome / Edge / Firefox 打开即可。不需要服务器，也不需要联网。

## 玩法

- 依次点击两个**颜色相同**的色块。
- 连接线只能水平或垂直，最多转弯 **2 次**；也可以从棋盘边缘外绕行。
- 你和电脑同时抢着消除，限时 **60 秒**。消除更多色块的一方获胜。
- 没有可消除组合时，棋盘会自动重排。
- 按 `H` 获取提示，按 `P` 或 `Esc` 暂停。
- 可选三档电脑速度：轻松 4.4 秒/手、标准 3.0 秒/手、挑战 1.9 秒/手。

## 文件说明

- `index.html`：页面结构与开始、暂停、帮助、结算界面。
- `style.css`：视觉样式、棋盘布局与动画。
- `logic.js`：棋盘生成、同色匹配、最多两转弯寻路、重排逻辑。
- `game.js`：游戏流程、实时计时、电脑对手、提示、暂停与结算。

## 操作小贴士

- 先扫视边缘和四角，这些位置的色块通常更容易连。
- 点错颜色会自动把选择切换到新色块，不需要先取消。
- 不确定时按 `H`，会有一对可消除色块闪动提示。
